OneDrive on Linux, as a real desktop app

Microsoft does not make a OneDrive app for Linux. OneDrive for Linux puts OneDrive on the web in a proper desktop window, opens Word, Excel and PowerPoint documents in Office on the web, and shows downloads with progress, for work and personal accounts.

  • Accounts: work or school (onedrive.cloud.microsoft, which opens your organisation's OneDrive) and personal (onedrive.live.com); run both at once with profiles.
  • Office documents: Word, Excel and PowerPoint open in Office on the web, in an app window or in your browser (officeLinks.openIn).
  • "Open in desktop app" links (ms-word:, ms-excel:, ms-powerpoint: and other Office schemes) open the document in Office on the web, since Linux has no Office desktop app.
  • Downloads with progress on the taskbar and a notification when done.
  • Uploads by drag and drop or the file picker, as on the web.

Install OneDrive for Linux

Download the package for your system from the latest release, then:

DistributionCommand
Fedora, RHEL, openSUSEsudo dnf install ./onedrive-for-linux-*.x86_64.rpm
Ubuntu, Debian, Linux Mintsudo apt install ./onedrive-for-linux_*_amd64.deb
Any distribution (AppImage)chmod +x onedrive-for-linux-*.AppImage && ./onedrive-for-linux-*.AppImage
Any distribution (tar.gz)extract, then run ./onedrive-for-linux

Every release lists SHA-256 checksums: sha256sum -c SHA256SUMS --ignore-missing.

Secure by design

  • Electron's sandbox and context isolation stay on for every window; pages cannot reach Node.js.
  • Permissions (notifications, clipboard) only for Microsoft's own pages.
  • Hardened binary: no ELECTRON_RUN_AS_NODE, NODE_OPTIONS, --inspect or remote debugging; sign-in cookies encrypted with your desktop keyring.
  • No telemetry or tracking added by the app. Privacy statement.

Frequently asked questions

Is there a OneDrive app for Linux?

Microsoft does not publish one. OneDrive for Linux is a free, open-source desktop app by Bhavesh Panchal that runs OneDrive on the web in its own window, with Linux desktop integration.

Does it sync my files to disk?

No. It is the OneDrive web client in a desktop window. For folder sync use abraunegg/onedrive or rclone; both work alongside this app.

Can I open Word, Excel and PowerPoint files?

Yes. Documents open in Office on the web, in an app window or in your browser. "Open in desktop app" links (ms-word:, ms-excel:, ms-powerpoint:) also open in Office on the web.

Does it work with work and personal accounts?

Yes. Work or school accounts (your organisation's SharePoint OneDrive) and personal accounts both work, side by side with profiles.

Is it official or safe?

It is unofficial and not affiliated with Microsoft. It keeps Electron's sandbox on, sends no telemetry, and its source is public on GitHub.
