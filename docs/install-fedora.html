Install OneDrive on Fedora

OneDrive on Fedora, RHEL and openSUSE in one command, as a desktop app with tray icon and notifications.

Download for Linux View on GitHub

Install with dnf

  1. Download onedrive-for-linux-<version>.x86_64.rpm (or .aarch64.rpm on ARM) from the latest release.
  2. Install it: sudo dnf install ./onedrive-for-linux-*.x86_64.rpm
  3. Start OneDrive for Linux from your application menu, or run onedrive-for-linux.
  4. Sign in with your work or school account (it opens your organisation's OneDrive) or your personal Microsoft account. For both at once: onedrive-for-linux --profile=personal --account=personal.

After installing

Word, Excel and PowerPoint files open in Office on the web. Set "officeLinks": { "openIn": "browser" } in ~/.config/onedrive-for-linux/config.json to open them in your browser instead.

Update or remove

The app tells you when a new release is out (Help › Check for Updates). Install the new RPM the same way. Remove it with sudo dnf remove onedrive-for-linux.

openSUSE

Use sudo zypper install ./onedrive-for-linux-*.x86_64.rpm instead of dnf.
